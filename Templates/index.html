GlucoTrend

Continuous Glucose Forecasting

GlucoTrend is a machine learning project that analyzes continuous glucose monitoring data and predicts future glucose levels using lifestyle, physiological and recent glucose information.

Machine Learning Pipeline

  • Data Upload
  • Data Summary
  • Exploratory Data Analysis
  • Feature Scaling
  • Missing Value Handling
  • Encoding
  • Linear Regression
  • Decision Tree Regression
  • Random Forest Regression
  • Gradient Boosting Regression
  • K-Means Clustering
  • Logistic Regression

Forecasting Target

The system uses current and recent observations to forecast the glucose value approximately 15 minutes into the future.
